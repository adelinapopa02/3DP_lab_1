SGM-Census with mono-depth initial guess
========================================

---
## Instructions

**Building (Out-of-Tree)**

    mkdir build
    cd build/
    cmake ..
    make
    
**Usage (from build/ directory)**

    ./sgm <data folder> <output disparity file> <disparity range>

**Examples**

    ./sgm ../Examples/Rocks1/ out.png 85
